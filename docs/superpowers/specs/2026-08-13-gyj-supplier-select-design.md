# GYJ 供应商选择修复设计

## 目标

修复项目后台创建 GYJ 采购入库单时，供应商选择控件点击后未出现下拉列表而超时的问题。

## 范围

- 仅调整 `GYJPlaywrightPage.select_header("供应商", ...)`。
- 若新增表单已显示“昆山怡口净水”，直接确认该值，不再打开下拉框。
- 未选中时，点击供应商字段内实际可聚焦的输入/选择控件；根据该控件已展开状态及其关联的下拉列表定位选项。
- 保持仓库、结算账户使用 GYJ 页面默认值；保持“仅保存、不审核”规则不变。

## 不在范围内

- 不读取令牌、Cookie 或浏览器本地存储。
- 不改 GYJ 登录流程、明细录入、序列号拆分或保存按钮。
- 验证过程中不保存采购入库单，除非用户另行明确要求。

## 验证

1. 添加回归测试：供应商已默认选中时不点击下拉；未选中时根据实际控件关联的下拉选择供应商。
2. 先运行该测试并确认旧实现失败。
3. 实现最小修复后运行 GYJ 入库测试集与完整测试集。
4. 用项目后台实际打开采购入库表单，确认不再出现等待 `.ant-select-dropdown:visible` 的超时；本次停在表单，不点击保存。
