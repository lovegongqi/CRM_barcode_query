# 账号页当前账号状态条紧凑化设计

## 目标

账号管理页的“当前工具账号”区域改为与其他业务页状态条一致的紧凑高度，减少页面切换时的纵向跳动。

## 设计

- 删除区域标题“当前工具账号”。
- 保留当前登录账号与角色信息，单行显示为 `admin（管理员）` 这一类状态内容。
- 标题栏不放退出入口；“退出工具账号”放回各页的账号状态区域。
- 账号管理页的紧凑状态条左侧显示当前账号与角色，右侧显示退出按钮。
- 使用账号页专用类约束紧凑状态条，避免改变其他卡片和移动端布局。
- 不改变导航栏、系统配置、CRM 批量登录、账号设置和账号列表的功能或宽度。

## 验收标准

- 模板中不再出现账号状态卡片的 `h2` 标题。
- 状态条保持单行，桌面端高度与其他页面状态条一致。
- 当前账号和角色仍然可见。
- 退出按钮不出现在标题栏，并在账号状态区域内可见。
- 五个业务页面的标题区和导航栏位置不受影响。
- 现有前端与路由测试全部通过。
