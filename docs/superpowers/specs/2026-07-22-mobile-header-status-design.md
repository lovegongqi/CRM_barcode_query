# 手机端标题与状态栏调整设计

## 目标

统一五个工作页在手机端的页头布局，并精简查询页、移库页的账号状态信息。

## 范围

- 工作页：查询、结果、移库、条码匹配、设置。
- 仅调整手机端标题区域；桌面端布局保持不变。
- 查询页和移库页删除状态栏中的“工具账号：admin”文字。
- 保留浏览器状态、CRM 登录状态和“退出工具账号”按钮。

## 布局

- logo 与标题区域组成同一横向标题行。
- logo 位于标题左侧，标题区域包含英文眉题、中文标题和副标题。
- logo 与标题垂直居中，沿用现有 12px 页面边距和 Aurora 玻璃风格。
- 查看日志按钮继续位于右上角，不与标题或 logo 重叠。
- 底部导航栏继续固定在底部，当前改动不改变其尺寸或定位。

## 实现方式

- 沿用现有模板结构和共享 `aurora.css`，不新增组件或路由。
- 使用手机端共享样式把独立 logo 对齐到标题左侧，并为标题预留宽度。
- 在查询页、移库页模板中移除账号文字节点，不影响退出按钮和后台登录状态。

## 验收标准

- 320px、390px、430px 三种手机宽度下，五个工作页的 logo 均位于标题左侧。
- 标题、查看日志按钮、状态栏均无重叠，页面无横向溢出。
- 查询页、移库页不再显示工具账号文字。
- 查询页、移库页仍显示退出工具账号按钮。
- 桌面端标题、logo 和导航布局不发生变化。
- 自动化测试、页面控制台检查和逐页视觉检查全部通过。
