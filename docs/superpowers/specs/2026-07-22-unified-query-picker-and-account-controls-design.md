# 查询通道、结果操作与工具账号统一设计

## 目标

在不改变查询调度、结果筛选及账号会话逻辑的前提下，统一电脑端与手机端的查询通道选择方式、手机端结果操作按钮尺寸，以及五个工作页面的工具账号与退出入口。

## 范围

本次只调整以下页面与共享样式：

- 在线查询：`templates/crm.html`
- 结果管理：`templates/index.html`
- CRM 移库：`templates/transfer.html`
- 条码匹配：`templates/product_library.html`
- 账号管理：`templates/accounts.html`
- 共享主题：`static/aurora.css`
- 前端契约测试：`tests/test_frontend_contract.py`

不调整 CRM 登录、查询任务调度、移库流程、结果数据、权限判断和文件保存逻辑。

## 查询通道下拉多选

电脑端不再显示横排的十个通道按钮，而是与手机端共用位于“查询通道”标题右侧的下拉多选触发器。触发器显示 `已选 N/总数 ⌄`，下拉层包含“全选通道”和每个查询通道的复选项，并继续显示“在线 / 待验证 / 未登录”状态。

电脑端与手机端继续共用 `selectedQuerySlotIds`，不增加第二份选择状态。默认全选，选择写入现有本地存储；取消最后一个通道时恢复全选并提示。点击组件外部或按 Escape 关闭下拉层。电脑端下拉层锚定触发器右侧并适当加宽，内容过多时只在下拉层内部滚动，不产生页面级横向滚动。

为避免保留不可见的重复界面，现有 `#querySlotSelector` 横排按钮区域从模板和渲染逻辑中删除；现有手机菜单改为全尺寸共用菜单，ID 与选择函数保持不变以降低改动范围。

## 手机端结果操作按钮

结果管理页的九个批量操作按钮在宽度不超过 640px 时使用固定三列网格，形成 3×3 排列。九个按钮等宽、等高，字体缩小到约 11px，并保持单行居中；颜色和操作语义保持现状。电脑端继续使用现有自适应横排按钮，不改变高频办公操作密度。

## 工具账号与退出入口

五个工作页面的账号状态栏统一为右侧紧凑组合：

`admin　[退出工具账号]`

其中账号位置只显示实际用户名，不显示“当前工具账号：”“工具账号：”或“（管理员）”。用户名紧邻退出按钮左侧，电脑端和手机端一致。查询页和移库页左侧原有浏览器、CRM 登录状态继续保留；结果管理、条码匹配和账号管理页删除左侧独立账号说明，只保留右侧组合。

每个页面沿用现有账号状态接口和更新函数，将已有账号元素移动到退出按钮前；不新建会话接口。未登录时用户名显示为 `未登录`。组合在窄屏保持单行，用户名过长时省略显示，退出按钮不可收缩。

## 验证标准

- 电脑端和手机端查询页只显示一个通道下拉入口，默认 `已选 10/10`。
- 下拉层可逐项勾选、全选、点击外部关闭和按 Escape 关闭，查询仍按所选通道自动调度。
- 电脑端不再出现横排通道按钮，页面没有新增横向滚动。
- 430px 宽度下结果页九个操作按钮为 3×3 等尺寸布局，长标签保持单行。
- 五个工作页面均在退出按钮左侧显示纯用户名，且不存在“当前工具账号”或“工具账号：admin（管理员）”等重复文案。
- 电脑端和手机端账号组合均不溢出状态栏。
- 全量自动化测试通过，并分别在电脑端和 430px 手机端检查查询、结果、移库、匹配和账号页面。
