# 入库页深色高对比样式

## 目标

修复 `/inbound` 中白底组件与深色极光主题冲突、文字对比不足的问题，不改变任何装箱单、CRM 或 GYJ 的业务行为。

## 方案

- 删除 GYJ 采购入库区的“当前阶段 / 入库明细 / 保存规则”三张状态卡；实时日志和保存结果保留。
- 历史装箱单、进度统计、汇总、每页行数和产品卡片改为深蓝半透明背景，并使用现有的深色边框体系。
- 所有正文和标题改为浅色高对比文本；辅助文本使用可读的蓝灰色；编码、数量与可复制内容使用青蓝色强调。
- “展开条码”、历史操作和批次复制按钮采用深色按钮面与浅色文字，保留删除按钮的红色语义。
- 条码与无条码配件标签采用深色底和清晰描边，避免纯白底。
- GYJ 卡片删除后，原有阶段和进度信息改写入“保存结果”，确保登录与保存反馈不会丢失。
- 入库导航图标使用与“移库”一致的双向箭头语义，并改为上下方向（`⇅`）。
- 小屏布局保持现有单列结构，仅调整颜色与对比度。

## 验收

- 产品标题、编码、件数、按钮和无条码配件标签在深色背景上均清晰可读。
- 页面内不再出现用于这些入库结果组件的白色或浅灰色实底。
- GYJ 区不再显示三张状态卡。
- 入库导航显示上下双向箭头，而非单向下载箭头。
- 现有入库模板与前端契约测试保持通过。
